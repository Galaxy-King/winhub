# Структура репозиторію

| Шлях | Призначення |
| --- | --- |
| `core` | Auth, security, database, Agent Gateway, admin, SDK. |
| `modules` | Infrastructure, HistoryAudit, Newsletter. |
| `templates` | Загальні Flask templates. |
| `static` | CSS, JS, vendor assets. |
| `migrations` | Alembic migrations. |
| `deploy/debian` | Install, update, backup, restore, systemd і Nginx. |
| `deploy/import_templates` | Готові task/report packs. |
| `WinHUBAgent` | Windows agent. |
| `WinHUBLinuxAgent` | Linux agent. |
| `WinHUBMacAgent` | macOS agent. |
| `tests` | Security і feature regression tests. |
| `WinHUB-WiKi` | Confluence-ready documentation. |

Runtime secrets/data не повинні з’являтися у project tree.
