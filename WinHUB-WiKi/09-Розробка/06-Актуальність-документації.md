# Актуальність документації

Перевірено 2 вересня 2026 року проти `main` (`afcf80b`, PR #31) та змін структури цього checkout. Локальні зміни Linux/macOS агентів збережені.

| Область | Що звірено й оновлено |
| --- | --- |
| Структура | Окремі сервер, Windows/Linux/macOS агенти та Wiki; нові шляхи CI і build scripts |
| Fresh install | Лише серверні файли, п'ять незалежних secrets, підготовка Python перед перевіркою адреси, відновлення перерваного setup |
| Update | Підготовлений checkout/release, backup до копіювання, перехід зі старого `/opt/winhub` |
| Reports | Safe formatted preview, email/Confluence, revisions і delivery snapshots |
| AI | Обробка всіх доступних звітів, current report як джерело, окремі permissions |
| Renderer | Bounded `range` та read-only loop metadata |
| API keys | IP/CIDR, scoped group actions, approved templates, безпечний job status |
| macOS | .NET 10, docs/tests у власних каталогах, спільний Linux Worker |
| Git/release | Дозволені компоненти, виключення runtime data, secrets, кешів і пакетів |

Значення у прикладах є placeholders. Ця звірка коду й документації не замінює пробне встановлення, upgrade і restore на окремій чистій Debian VM перед production rollout.

## Виконані перевірки

- 96 серверних regression tests, 7 контрактних тестів macOS та 4 тести серверного пакування/копіювання/секретів у Linux/WSL — успішно.
- Windows, Linux і managed macOS validation target збираються без warnings/errors; Linux/macOS protocol self-tests успішні.
- Managed publish macOS зберігає перенесену інструкцію в `docs/`.
- Bash syntax і PowerShell parser checks пройдено.
- 310 файлів у підготовленому Git index: немає runtime data, secrets-файлів, кешів, архівів або build outputs; локальні Markdown-посилання існують.
- Серверний release містить 143 файли; у ньому немає агентів, Wiki, тестів, кешів, БД чи ключів. SHA-256 відповідає manifest.

Native macOS signing/notarization і запуск служб на чистій Debian VM під час цієї перевірки не виконувалися.
