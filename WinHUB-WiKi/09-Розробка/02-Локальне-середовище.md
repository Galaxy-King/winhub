# Локальне середовище

Перейдіть у `WinHUB/`, створіть Python virtual environment і встановіть dependencies із `requirements.txt`. Для Windows/Linux потрібен .NET 8 SDK, для macOS — .NET 10. macOS NativeAOT build виконується на Apple Silicon Mac; запускати dotnet потрібно з `WinHUBMacAgent/`, щоб використовувався його `global.json`.

Local environment має використовувати окремі development secrets, database і certificates. Не копіюйте `/etc/winhub/winhub.env` із production.

Production server запускається через `server_debian.py`; local entrypoint і debug behavior перевіряйте в поточній версії репозиторію. Debug server не публікуйте у мережу.

Перед commit перевірте `git diff` на tokens, private keys, passwords, internal URLs і generated artifacts.
