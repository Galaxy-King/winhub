# Ідентичність клонованих агентів

## Рішення

WinHUB не використовує збіг hostname, MAC/fingerprint або старого token як дозвіл на автоматичне видалення чи перенесення endpoint-а. Такі збіги є сигналами для Review Center. `Keep Both` зберігається як виняток конкретної пари endpoint ID.

Клонування вже enrolled VM копіює `agent.hwid`, token, RSA key і task-signing state. Тому сучасний агент додає до підписаних запитів process session ID, boot ID, hashed platform fingerprint і capability `identity-session-v1`. Сервер відкриває конфлікт лише після доказу паралельної активності двох session одного endpoint-а. Послідовна заміна session під час звичайного restart не є конфліктом.

## Fail-closed dispatch

Відкритий або такий, що розв'язується, identity conflict блокує видачу нових задач. Heartbeat, telemetry та результати вже виданих задач приймаються з `instance_session_id`. Це зберігає діагностику, але не дозволяє випадковій VM отримати адміністративну команду.

## Розділення

Адміністратор вибирає конкретну активну session. Сервер створює окремий approved endpoint і одноразову команду з новими endpoint ID та token. Команда:

- доставляється лише цільовій session;
- входить у RSA-PSS v2 task envelope;
- має строк дії;
- повторно повертається цій session до завершення або expiry.

Агент перевіряє envelope і target session, генерує нову RSA identity, записує нові ID/token, скидає task-signing pin, архівує identity-bound journals і перезапускається. Перший підписаний poll нової identity завершує команду та конфлікт. Групи копіюються; стара task/telemetry history не перепризначається, бо її походження після clone collision неоднозначне.

## Межі

Старі агенти без session capability не підтримують remote split і потребують update або purge/reinstall. Native macOS signing/notarization та live split двох VM є release gates і не замінюються managed build на Windows.

Для golden image рекомендований `--prepare-clone-template PREPARE-CLONE`: він прибирає WinHUB identity і secrets до клонування, але не створює багаторазовий bootstrap secret усередині template.
