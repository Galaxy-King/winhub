# Аудит і діагностика Newsletter

Перевіряйте campaign status, `winhub-newsletter` journal, Audit Log, mail profile test, LDAP test та failed mailbox folder.

## Типові проблеми

| Повідомлення | Дія |
| --- | --- |
| No profiles configured | Створіть і протестуйте SMTP profile. |
| No lists created yet | Створіть recipient list. |
| Sender profile not found | Перевірте profile/route mapping. |
| Mail server connection failed | DNS, port, TLS, outbound allowlist і credentials. |
| GPG is unavailable | `GPG_PATH`, package і permissions. |
| Missing/Invalid GPG Key | Fingerprint і recipient key. |
| Attachment size limit exceeded | Зменште attachment або змініть policy обґрунтовано. |
| Worker heartbeat missing | `systemctl status winhub-newsletter`, потім journal служби. |
| Inbound signature is not approved | Перевірте підпис і додайте точний fingerprint у mailbox route. |

Перед передаванням діагностики маскуйте email addresses, subject, credentials і decrypted body.
