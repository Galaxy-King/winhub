# Основні терміни

| Термін | Значення |
| --- | --- |
| Endpoint | Керований вузол із встановленим агентом. |
| Agent | Системна служба, яка опитує WinHUB і виконує дозволені задачі. |
| Enrollment | Перша захищена реєстрація агента на сервері. |
| Pending | Новий endpoint очікує рішення адміністратора. |
| Approved | Endpoint підтверджений і може отримувати задачі. |
| Blocked | Сервер не дозволяє endpoint виконувати звичайну роботу. |
| Template | Опис дії, параметрів, script і формату звіту. |
| Template Secret | Секрет, доступний шаблону без публікації у WiKi або task payload. |
| Task | Конкретний запуск шаблону на endpoint. |
| Job | Груповий запуск задач на кількох endpoint-вузлах. |
| Telemetry | Періодичні дані про стан, ресурси та активність вузла. |
| Metric Item | Останнє значення спеціальної метрики endpoint-а. |
| Task v2 | Per-agent RSA-PSS підпис задачі із sequence-захистом. |
| Recovery bundle | Одноразовий архів для аварійного відновлення нового сервера. |
