# Порти та системні каталоги

## Мережеві порти

| Порт | Призначення | Доступність |
| --- | --- | --- |
| `22/tcp` | SSH адміністрування | Лише довірені адміністративні мережі. |
| `80/tcp` | Redirect на HTTPS | За потреби. |
| `443/tcp` | Web UI, API та агенти | Основний зовнішній порт. |
| `8443/tcp` | Локальний backend | Тільки `127.0.0.1`, не відкривати у firewall. |
| `5432/tcp` | PostgreSQL | Тільки локально для single-server deployment. |
| `AGENT_PUBLIC_PORT` | Опційний agent-only listener | Відкривати лише коли він налаштований. |

## Каталоги Debian-сервера

| Шлях | Призначення |
| --- | --- |
| `/opt/winhub` | Код, Git checkout, virtual environment і deploy scripts. |
| `/etc/winhub/winhub.env` | Production-конфігурація та необхідні runtime-секрети. |
| `/etc/winhub/certs` | TLS certificate та private key. |
| `/var/lib/winhub` | Runtime data, encryption keys, packages і reports. |
| `/var/log/winhub` | Серверні журнали. |
| `/run/winhub-renderer.sock` | Socket ізольованого renderer. |

## Принцип доступу

Backend слухає лише localhost. Агенти й користувачі працюють через HTTPS на Nginx. Файли секретів не повинні мати права читання для `other`.
