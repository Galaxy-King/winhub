# API keys

API key використовується для автоматизованого доступу з обмеженим набором permissions.

## Правила

- окремий key для кожної інтеграції;
- мінімальні permissions;
- зрозуміла назва й owner;
- передавання лише через secret manager;
- не вставляти key у URL, WiKi, Git або log;
- регулярна rotation;
- негайне revoke при інциденті або завершенні інтеграції.

Після створення перевірте API call із мінімальним доступом і переконайтеся, що заборонені endpoints повертають denial.
