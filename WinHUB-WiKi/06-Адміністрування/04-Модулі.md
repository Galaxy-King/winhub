# Модулі

WinHUB завантажує modules через registry і manifest.

Поточні основні modules:

- `Infrastructure` — Endpoint Management;
- `HistoryAudit` — Audit & History;
- `Newsletter` — розсилки.

## Адміністрування

- перевіряйте module status і version;
- вимикайте module лише після перевірки dependencies;
- доступ користувачів контролюється module grants;
- custom module code проходить review і tests;
- manifest не повинен містити secrets або environment-specific data.
