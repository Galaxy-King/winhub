# Аварійні процедури

## Backend unavailable

1. Перевірте disk/CPU/RAM.
2. Перевірте PostgreSQL.
3. Перевірте `journalctl -u winhub`.
4. Перевірте env permissions і migrations.
5. Не відкривайте backend port назовні як workaround.

## Невдале оновлення

Використайте перевірений backup:

```bash
sudo /opt/winhub/deploy/debian/rollback_winhub.sh \
  /var/lib/winhub/backups/<UTC_TIMESTAMP>
```

## Сертифікат прострочений

Встановіть новий cert/key, перевірте permissions і Nginx, потім оновіть agent trust/pin контрольованою хвилею. Не вимикайте TLS verification.

## Втрата encryption key

Зупиніть зміни й відновіть відповідний файл із encrypted trusted backup. Не генеруйте новий key поверх існуючих encrypted data.
