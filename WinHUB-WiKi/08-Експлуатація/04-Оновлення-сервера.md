# Експлуатаційний процес оновлення сервера

## До maintenance window

- прочитайте release notes;
- перевірте disk space;
- переконайтеся у свіжому off-host backup;
- визначте rollback backup;
- зупиніть масовий agent rollout;
- повідомте операторів.

## Виконання

```bash
cd /opt/winhub
sudo bash deploy/debian/update_winhub.sh <OPTIONAL_GIT_REF>
```

## Acceptance

- healthcheck;
- login і dashboard;
- Review Center;
- test agent poll/task/result;
- report renderer;
- critical integration test;
- Production Readiness.

При системній помилці припиніть зміни й використайте затверджений rollback, а не ручне змішування версій файлів.
