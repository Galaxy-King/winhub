# Моніторинг і логи

## Основні сигнали

- HTTP health і latency;
- CPU, RAM, disk, inode;
- PostgreSQL connections і storage;
- Nginx 4xx/5xx;
- service restarts;
- queue depth і failed tasks;
- agent poll/telemetry freshness;
- renderer failures;
- backup age;
- certificate expiry.

## Логи

```text
/var/log/winhub/winhub_prod.log
/var/log/nginx/access.log
/var/log/nginx/error.log
journalctl -u winhub
journalctl -u winhub-renderer.socket
```

Не вмикайте надмірний debug logging у production без часового обмеження. Log export підлягає redaction.
