# Змінні сервера

| Група | Основні змінні |
| --- | --- |
| Runtime | `WINHUB_ENV`, `HOST`, `PORT`, `DATA_DIR`, `SERVER_LOG_FILE` |
| Database | `POSTGRES_HOST`, `POSTGRES_PORT`, `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` |
| TLS | `SERVER_CERT_PATH`, `SERVER_KEY_PATH` |
| Sessions | `SECRET_KEY`, cookie flags, idle/absolute timeout |
| Agent listener | `AGENT_PUBLIC_PORT`, `AGENT_PUBLIC_BASE_URL`, package URL mode |
| Enrollment | API key, enabled, allowlist, reenroll, rate limit |
| Signatures | HMAC secret, signature mode, signed requests, max skew |
| Polling | idle/task/pending interval, jitter, telemetry interval |
| Security | HSTS, CSP, CSP nonce, outbound policy, renderer mode |
| Історія | `HISTORY_SEARCH_KEY`, `HISTORY_RETENTION_DAYS`, `TELEMETRY_RETENTION_DAYS`, cleanup/backfill batch sizes |
| AI | `AI_ALLOW_INSECURE_HTTP`, `AI_MAX_HTTP_RESPONSE_BYTES`, timeout, worker interval, prompt/input/output limits |
| AI code validator | `CODE_VALIDATOR_SOCKET` — [налаштування ізольованого редактора](../guides/features/AI_TEMPLATE_EDITOR_UA.md) |
| API keys | `TRUSTED_PROXY_CIDRS`; IP/CIDR, групи й шаблони налаштовуються в UI |
| Newsletter | SMTP, IMAP, LDAP, FreeIPA, GPG |

Повний актуальний список дивіться у [WinHUB/deploy/debian/winhub.env.example](../../WinHUB/deploy/debian/winhub.env.example). Реальний `/etc/winhub/winhub.env` не копіюйте до WiKi.
