# Команди адміністратора

## Статус

```bash
sudo systemctl status winhub --no-pager
sudo systemctl status winhub-renderer.socket --no-pager
sudo nginx -t
sudo /opt/winhub/deploy/debian/healthcheck_winhub.sh
```

## Логи

```bash
sudo journalctl -u winhub -n 100 --no-pager
sudo tail -n 100 /var/log/winhub/winhub_prod.log
```

## Оновлення

```bash
sudo /opt/winhub/deploy/debian/update_winhub.sh
```

## Backup

```bash
sudo /opt/winhub/deploy/debian/backup_winhub.sh
```

## Security check

```bash
sudo /opt/winhub/deploy/debian/security_smoke_test.sh
```

Не вставляйте output команд із секретними значеннями до Confluence без redaction.
