# Параметри агентів

| Параметр | Призначення |
| --- | --- |
| `ServerUrl` | HTTPS URL WinHUB. |
| `PollIntervalSeconds` | Базовий poll interval. |
| `PollJitterSeconds` | Випадкова затримка між agents. |
| `StartupSpreadSeconds` | Рознесення першого poll. |
| `DefaultTaskTimeoutSeconds` | Default task timeout. |
| `MaxResultLogBytes` | Maximum returned log. |
| `ServerCertificateSha256` | TLS certificate pin. |
| `RequireTaskSignature` | Обов’язкова signature validation. |
| `ExecutionMode` | `disabled`, `allowlist` або `full`. |
| `AllowedActions` | Дозволені actions у allowlist mode. |
| `AllowCrossHostUpdateDownloads` | Дозвіл update download з іншого host. |
| `RestartAfterConsecutivePollFailures` | Self-heal threshold. |

Параметри Task v2 public key/sequence є керованим state агента. Не заповнюйте їх вручну й не копіюйте між endpoint-вузлами.
