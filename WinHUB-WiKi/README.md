# WinHUB WiKi для Confluence

Цей каталог містить документацію WinHUB у Markdown. Структура розділяє:

- загальну інформацію про систему;
- практичне встановлення та налаштування сервера;
- життєвий цикл кожного типу агента;
- інструкції користувача й адміністратора;
- експлуатацію, безпеку, розробку та довідкові матеріали.

## Імпорт до Confluence

1. Створіть у Confluence головну сторінку `WinHUB`.
2. Імпортуйте `00-Головна.md` як дочірню або використайте її вміст для головної сторінки.
3. Імпортуйте сторінки розділів у порядку з [SUMMARY.md](SUMMARY.md).
4. Відтворіть parent-child зв’язки за [картою імпорту](CONFLUENCE-IMPORT-MAP.md).
5. Після імпорту перевірте відносні посилання та блоки коду.

Назви файлів мають числовий префікс лише для стабільного сортування. Заголовок `H1` усередині файла є рекомендованою назвою сторінки Confluence.

## Правило безпеки

Документація не містить реальних паролів, ключів, токенів, приватних адрес або recovery-архівів. Не додавайте такі дані під час перенесення до Confluence. Детальні правила наведені на сторінці [Безпека документації](01-Загальна-інформація/06-Безпека-документації.md).

## Джерело істини

Команди у WiKi мають відповідати скриптам поточної версії репозиторію. Перед публікацією нової версії перевіряйте сторінки встановлення, оновлення, резервного копіювання й агентів.
