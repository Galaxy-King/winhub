# Готові пакети шаблонів

У репозиторії є приклади import packs:

| Пакет | Призначення |
| --- | --- |
| Endpoint Compliance Audit | Аудит activation/compliance endpoint-а. |
| Chrome Extension Manager | Перегляд і керування Chrome extensions. |
| OpenVPN AS Inventory | Збір inventory OpenVPN Access Server. |
| Proxmox Inventory | Збір даних Proxmox. |
| System Localization | Керування localization settings. |
| Windows Service Manager | Операції зі службами Windows. |
| VSS + WinRAR Backup | VSS backup Windows folders на SMB. |
| Universal VSS Backup | [Універсальний backup-пакет](../../WinHUB/deploy/import_templates/universal_vss_backup/README_UA.md). |

Перед import прочитайте README конкретного пакета, перевірте scripts і створіть Template Secrets. JSON package не повинен містити реальних credentials.
