# Groups

Групи використовуються для доступу, bulk tasks, software rollout, scheduler, triggers та block/unblock.

## Створення

1. Відкрийте `Groups`.
2. Натисніть `Create Group`.
3. Вкажіть name і description.
4. Додайте перевірені endpoint-вузли.

## Робочий простір

`Groups Workspace` показує групи компактним списком. Поле пошуку фільтрує список за назвою та описом, а лічильник одразу показує кількість знайдених груп.

Після відкриття групи можна шукати хости, позначати один або декілька вузлів і виконувати масову дію:

- `Remove from group` — прибирає членство у цій групі, але **не видаляє node із WinHUB**;
- `Block selected` — забороняє вибраним агентам отримувати нові задачі;
- `Unblock selected` — повертає можливість отримувати задачі.

Масова операція обмежена 200 хостами за один запит. Сервер до внесення змін перевіряє permission, scope групи, scope кожного хоста і членство всіх вибраних хостів. Якщо хоча б один вузол не пройшов перевірку, операція не застосовується частково. Результат записується в Audit Log.

## Рекомендації

- групуйте за функцією, середовищем або власником;
- відділяйте `Test`, `Pilot` і `Production`;
- не використовуйте одну групу одночасно як security boundary і тимчасовий список;
- перед видаленням перевірте scheduler, trigger і user-access dependencies;
- використовуйте OS groups для platform-specific templates.

Bulk block є аварійною дією. Використовуйте її лише для потрібних позначених хостів і перевіряйте результат в Audit Log.
