# Встановлення Windows Agent

## Підготуйте пакет

Використовуйте versioned release package, створений `create-agent-release.ps1`, або перевірений пакет із WinHUB Agent Packages.

Розпакуйте до:

```text
C:\Program Files\WinHUBAgent
```

Не розгортайте `.pdb` на production endpoint.

## Підготуйте конфігурацію

Поруч з installer мають бути:

```text
winhub_agent.conf
winhub_agent.bootstrap.conf
```

У runtime config вкажіть URL і TLS pin. У bootstrap config вставте enrollment/task-signing значення із захищеного сховища. Не копіюйте їх із WiKi.

## Встановіть службу

Запустіть PowerShell від адміністратора:

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force
Set-Location "C:\Program Files\WinHUBAgent"
.\install-service.ps1
```

Installer обмежує ACL для install/data/log directories до `SYSTEM` і локальних `Administrators`.

## Перевірте

```powershell
Get-Service WinHUBAgent
Get-Content "C:\ProgramData\WinHUB\logs\agent.log" -Tail 100
```

Після появи endpoint у `Pending Approval` перевірте деталі й виконайте `Approve`. Переконайтеся, що plaintext bootstrap config видалений агентом після успішної міграції.
