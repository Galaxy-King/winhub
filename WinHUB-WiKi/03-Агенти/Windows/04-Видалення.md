# Видалення Windows Agent

Запустіть PowerShell від адміністратора:

```powershell
Set-Location "C:\Program Files\WinHUBAgent"
.\uninstall-service.ps1
```

## Перед видаленням

- переконайтеся, що на endpoint немає активної задачі;
- зафіксуйте причину в change record;
- за потреби заблокуйте endpoint у WinHUB;
- визначте, чи потрібно зберігати локальні logs/state для розслідування.

## Після видалення

```powershell
Get-Service WinHUBAgent -ErrorAction SilentlyContinue
```

Запис endpoint у WinHUB не видаляється автоматично. Спочатку `Block` або `Reject`, а видалення server-side record виконуйте лише після перевірки audit/history requirements.

Не видаляйте `C:\ProgramData\WinHUB` вручну, якщо потрібне збереження forensic data або identity для контрольованого reinstall.
