# Інформація про Windows Agent

Windows Agent підтримує enrollment, signed poll, telemetry, signed tasks, result delivery і self-update.

## Локальний стан

- service binary: install directory;
- protected secrets: DPAPI store;
- identity key і hardware ID: protected data directory;
- logs: `C:\ProgramData\WinHUB\logs`;
- update backups: `C:\ProgramData\WinHUB\backups`.

Логи ротуються, а старі файли видаляються за вбудованою retention policy.

## Безпека

- ACL обмежуються `SYSTEM` і `Administrators`;
- після enrollment global API key видаляється з локального secret store;
- signed requests прив’язують timestamp, nonce і body hash;
- tasks перевіряються до виконання;
- TLS bypass не використовується у production.

## Збірка

Production release за замовчуванням створюється як self-contained NativeAOT `win-x64`. Managed single-file використовуйте лише для окремо обґрунтованого compatibility case.
