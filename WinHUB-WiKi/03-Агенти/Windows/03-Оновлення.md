# Оновлення Windows Agent

## Локальне оновлення

Скопіюйте versioned package на endpoint і запустіть PowerShell від адміністратора:

```powershell
Set-Location "C:\Program Files\WinHUBAgent"
.\update-service.ps1 -PackagePath "C:\Temp\WinHUBAgent-v<VERSION>-win-x64.zip"
```

Скрипт створює backup попередньої версії, зберігає runtime config і DPAPI secrets, замінює binaries та перевіряє службу.

## Remote self-update

1. Додайте перевірений agent package у WinHUB.
2. Перевірте version, platform, architecture і SHA-256.
3. Запустіть rollout на тестовій групі.
4. Використовуйте хвилі та delay для production.
5. Контролюйте статус у Fleet Center і Queue.

Agent update package не повинен містити production bootstrap config. Після rollout перевірте agent version, heartbeat і Task v2.
