# Діагностика Windows Agent

## Служба і журнал

```powershell
Get-Service WinHUBAgent
Get-Content "C:\ProgramData\WinHUB\logs\agent.log" -Tail 200
Get-EventLog -LogName Application -Source WinHUBAgent -Newest 30 |
  Select-Object TimeGenerated, EntryType, Message
```

## Перевірка мережі

```powershell
Test-NetConnection <WINHUB_SERVER> -Port 443
```

## Типові помилки

| Симптом | Перевірка |
| --- | --- |
| TLS error | SAN, trust chain, SHA-256 pin, системний час. |
| Enrollment rejected | enrollment window, bootstrap secret, allowlist, duplicate identity. |
| Signature expired | NTP/час endpoint-а і server skew policy. |
| Service restart loop | останні poll errors, config JSON, ACL, package integrity. |
| Task rejected | Task v2 key/sequence, platform action, Execution Mode. |

Не публікуйте повний log без маскування tokens, host information і task output.
