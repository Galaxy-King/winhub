# Налаштування Windows Agent

## Файли

```text
C:\Program Files\WinHUBAgent\winhub_agent.conf
C:\ProgramData\WinHUB\agent.secrets
C:\ProgramData\WinHUB\logs\agent.log
```

`agent.secrets` захищений DPAPI. Не копіюйте його між endpoint-вузлами.

## Рекомендовані значення

- `IgnoreTlsCertificateErrors`: `false`;
- `RequireTaskSignature`: `true`;
- `PollIntervalSeconds`: `30` або більше;
- `PollJitterSeconds`: не менше `30` для fleet;
- `StartupSpreadSeconds`: `120` або більше для GPO rollout;
- `RestartAfterConsecutivePollFailures`: `10`;
- `MaxResultLogBytes`: відповідно до server limit.

Після зміни runtime config перезапустіть службу:

```powershell
Restart-Service WinHUBAgent
```

Bootstrap secrets потрібні лише для першої реєстрації. Не відновлюйте bootstrap-файл після успішного enrollment.
