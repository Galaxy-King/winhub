# Налаштування Linux Agent

## Шляхи

```text
/opt/winhub-linux-agent
/etc/winhub-agent/winhub_agent.conf
/etc/winhub-agent/winhub_agent.bootstrap.conf
/var/lib/winhub-agent
```

Secret/state files мають права `0600`, directories — `0700`, owner — root.

## Execution Mode

- `disabled` — inventory/telemetry без task execution;
- `allowlist` — лише `AllowedActions`;
- `full` — необмежене віддалене виконання, тільки після окремого security decision.

Рекомендований default — `allowlist` із `agent_update`.

Після зміни:

```bash
sudo systemctl restart winhub-linux-agent
sudo systemctl status winhub-linux-agent --no-pager
```

`AllowCrossHostUpdateDownloads=false` залишайте вимкненим, якщо package downloads не проходять через окремо затверджений host.
