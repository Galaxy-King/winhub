# Встановлення Linux Agent

## Оберіть пакет

- `linux-x64` — більшість Intel/AMD серверів;
- `linux-arm64` — ARM64 сервери та SBC.

## Розпакуйте

```bash
sudo mkdir -p /tmp/winhub-linux-agent
sudo tar -xzf WinHUBLinuxAgent-v<VERSION>-linux-x64.tar.gz \
  -C /tmp/winhub-linux-agent
cd /tmp/winhub-linux-agent
```

## Додайте конфігурацію

Створіть `winhub_agent.conf` і одноразовий `winhub_agent.bootstrap.conf` на основі example-файлів. Реальні секрети отримайте із password/recovery storage, не з WiKi.

## Встановіть

```bash
sudo ./install-linux-agent.sh
```

## Перевірте

```bash
sudo systemctl status winhub-linux-agent --no-pager
sudo journalctl -u winhub-linux-agent -n 100 --no-pager
```

Підтвердьте endpoint у Review Center і перевірте, що bootstrap config видалено після enrollment.
