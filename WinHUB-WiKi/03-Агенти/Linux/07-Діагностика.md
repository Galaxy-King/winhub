# Діагностика Linux Agent

```bash
sudo systemctl status winhub-linux-agent --no-pager --full
sudo journalctl -u winhub-linux-agent -n 200 --no-pager
sudo /opt/winhub-linux-agent/WinHUBLinuxAgent --self-test
curl -I https://<WINHUB_SERVER>/api/health
```

## Перевірте

- правильний package architecture;
- system time/NTP;
- DNS і route до WinHUB;
- TLS trust або certificate pin;
- права `/etc/winhub-agent` і `/var/lib/winhub-agent`;
- enrollment window/allowlist;
- Execution Mode та Allowed Actions;
- вільне місце для pending results.

Не використовуйте `curl -k` як production-виправлення. Він може допомогти лише в ізольованій діагностиці certificate chain без передачі секретів.
