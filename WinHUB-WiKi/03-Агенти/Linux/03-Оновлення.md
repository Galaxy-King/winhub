# Оновлення Linux Agent

## На одному endpoint

Розпакуйте новий package і використайте `update-linux-agent.sh` згідно з package README. Runtime config, enrollment token та identity повинні зберегтися.

Після оновлення:

```bash
sudo systemctl status winhub-linux-agent --no-pager
/opt/winhub-linux-agent/WinHUBLinuxAgent --version
sudo journalctl -u winhub-linux-agent -n 100 --no-pager
```

## Через SSH rollout

`deploy-linux-agents.sh --action install` оновлює лише старішу версію. Для контрольованого reinstall використовуйте `--action reinstall`.

## Через WinHUB

Завантажте signed/versioned package, перевірте platform, architecture і SHA-256, потім запустіть agent rollout хвилями. Не змішуйте x64 та ARM64 в одному package rollout.
