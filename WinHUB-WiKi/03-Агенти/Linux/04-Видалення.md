# Видалення Linux Agent

## Збереження identity

```bash
sudo /opt/winhub-linux-agent/uninstall-linux-agent.sh
```

Стандартне видалення зберігає `/etc/winhub-agent` і `/var/lib/winhub-agent`, щоб контрольований reinstall не створював нову identity.

## Повне очищення

`--purge` видаляє конфігурацію, token, identity і pending results. Використовуйте purge лише коли справді потрібний новий enrollment або endpoint виводиться з експлуатації.

## Масово через SSH

```bash
./deploy-linux-agents.sh --action uninstall --hosts linux_hosts.txt --yes
```

Перед purge заблокуйте server-side endpoint і збережіть потрібні audit/forensic дані. Запис у WinHUB не видаляється автоматично.
