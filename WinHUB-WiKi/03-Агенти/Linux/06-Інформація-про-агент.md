# Інформація про Linux Agent

Linux Agent — self-contained .NET 8 service із signed enrollment/poll/telemetry/result protocol.

## Захист

- root-only config, identity, token і state;
- RSA signed requests із timestamp, nonce та body hash;
- per-agent RSA-PSS Task v2;
- sequence state і downgrade protection;
- TLS verification і certificate pinning;
- allowlist execution policy;
- package path/traversal validation.

## Надійність

Невідправлені результати зберігаються у:

```text
/var/lib/winhub-agent/pending-results
```

Після відновлення мережі або restart агент повторює відправлення. `RestartAfterConsecutivePollFailures` дозволяє systemd self-heal після серії помилок.

## Локальний self-test

```bash
sudo /opt/winhub-linux-agent/WinHUBLinuxAgent --self-test
```
