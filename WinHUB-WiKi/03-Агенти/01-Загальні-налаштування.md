# Загальні налаштування агентів

Агент використовує два різні конфігураційні файли.

## Runtime config

`winhub_agent.conf` містить несекретні або довготривалі параметри з’єднання:

```json
{
  "ServerUrl": "https://<WINHUB_SERVER>",
  "PollIntervalSeconds": 30,
  "PollJitterSeconds": 30,
  "StartupSpreadSeconds": 120,
  "DefaultTaskTimeoutSeconds": 1800,
  "MaxResultLogBytes": 262144,
  "IgnoreTlsCertificateErrors": false,
  "ServerCertificateSha256": "<CERTIFICATE_SHA256>",
  "RequireTaskSignature": true,
  "ExecutionMode": "allowlist",
  "AllowedActions": ["agent_update"],
  "AllowCrossHostUpdateDownloads": false,
  "RestartAfterConsecutivePollFailures": 10
}
```

Набір полів може відрізнятися між платформами. Використовуйте example-файл саме зі свого agent package.

## Bootstrap config

`winhub_agent.bootstrap.conf` потрібен лише для першого enrollment і містить секрети із захищеного recovery/password storage. Після успішної міграції агент видаляє plaintext bootstrap-файл.

Реальний bootstrap config не додавайте до Git, GPO archive, WiKi, ticket або software package library.

## Polling

- `PollIntervalSeconds` — базова затримка;
- `PollJitterSeconds` — випадкове рознесення запитів;
- `StartupSpreadSeconds` — стабільна затримка першого poll;
- сервер може повертати bounded scheduling hints;
- великі fleet не повинні опитувати сервер синхронно.

## TLS

У production використовуйте trusted CA, internal CA або certificate pinning. `IgnoreTlsCertificateErrors` завжди `false`.
