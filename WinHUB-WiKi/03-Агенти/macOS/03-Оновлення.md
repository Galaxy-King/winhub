# Оновлення macOS Agent

Managed update приймається лише коли package:

- має SHA-256, що збігається з WinHUB;
- має embedded version, що збігається з `target_version` rollout;
- містить допустимі archive entries;
- містить `arm64` binary з Hardened Runtime та identifier `com.winhub.agent`;
- підписаний тим самим Apple Team ID, що й встановлений agent;
- проходить version і service validation.

Під час update агент замінює runtime files і LaunchDaemon plist, запускає нову версію та перевіряє стабільність. При помилці виконується rollback.

## Після rollout

```bash
sudo launchctl print system/com.winhub.agent
tail -n 150 /Library/Logs/WinHUB/agent.log
```

У WinHUB перевірте agent version, heartbeat, rollout status і Task v2.

У Agent Packages завантажується `.tar.gz`, не інсталяційний `.pkg`.
