# Діагностика macOS Agent

```bash
sudo /Library/PrivilegedHelperTools/com.winhub.agent/diagnose-macos-agent.sh
sudo launchctl print system/com.winhub.agent
tail -n 200 /Library/Logs/WinHUB/agent.log
codesign --verify --deep --strict --verbose=2 <AGENT_BINARY>
codesign -dv --verbose=4 <AGENT_BINARY>
```

## Перевірте

- macOS version і Apple Silicon architecture;
- Developer ID signature та expected Team ID;
- code-signing identifier `com.winhub.agent`, Hardened Runtime і embedded version;
- TLS trust/pin і system time;
- ownership/permissions конфігів і state;
- LaunchDaemon plist;
- enrollment window;
- update package SHA-256;
- Execution Mode та Allowed Actions.

Якщо update відкотився, не обходьте signature check. Перевірте package contents, code signature, Team ID, log і service stability.
