# Налаштування macOS Agent

Рекомендований runtime config:

- `IgnoreTlsCertificateErrors=false` — bypass на macOS production не підтримується;
- `RequireTaskSignature=true`;
- `ExecutionMode=allowlist`;
- `AllowedActions=["agent_update"]`;
- `AllowCrossHostUpdateDownloads=false`;
- `RestartAfterConsecutivePollFailures=10`.

Для inventory-only використовуйте `ExecutionMode=disabled`. `full` вмикайте лише після окремого security approval.

Configuration, token, RSA identity і bootstrap secrets мають root-only permissions. Bootstrap
file видаляється після migration, а enrollment key — з local secret state після успішного
enrollment. Контрольований re-enrollment потребує повторного надання короткоживучого key.

Підпис Developer ID не надає TCC permissions. Full Disk Access, Accessibility, Screen
Recording та інші PPPC дозволи додавайте через MDM лише коли вони реально потрібні дозволеним
scripts; baseline telemetry, FileVault inventory, enrollment і self-update їх не потребують.

Після зміни перезапустіть LaunchDaemon через штатний agent script або затверджену launchctl-процедуру і перевірте log.
