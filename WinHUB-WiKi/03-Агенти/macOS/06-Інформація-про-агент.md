# Інформація про macOS Agent

Агент працює як root LaunchDaemon, оскільки керує root-owned installation і self-update.

## Secure defaults

- обов’язкова TLS validation;
- signed tasks;
- allowlist execution policy;
- SHA-256 package verification;
- Apple code-signature і Team ID pinning;
- archive traversal/link/special-file protection;
- root-only secrets та identity;
- service validation і rollback після update.
- обмеження часу/обсягу task output і persistent result queue;
- `newsyslog` rotation для stdout/stderr.

## Підтримка

- platform: macOS 14+;
- architecture: Apple Silicon `osx-arm64`;
- runtime: self-contained .NET 10 LTS Native AOT;
- service manager: launchd.

Лог:

```text
/Library/Logs/WinHUB/agent.log
```
