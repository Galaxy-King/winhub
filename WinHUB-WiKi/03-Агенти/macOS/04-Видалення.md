# Видалення macOS Agent

У каталозі agent package або install directory:

```bash
sudo ./uninstall-macos-agent.sh
```

Перед видаленням перевірте active tasks, зафіксуйте change і за потреби заблокуйте endpoint у WinHUB.

Після виконання:

```bash
sudo launchctl print system/com.winhub.agent
```

Команда повинна повідомити, що service не знайдений. Server-side endpoint record зберігається до окремого рішення адміністратора.

Не видаляйте state/identity вручну, якщо планується контрольований reinstall зі збереженням enrollment.

Для повного незворотного видалення configuration, enrollment identity, backup-ів і logs:

```bash
sudo ./uninstall-macos-agent.sh --purge
```

Перед `--purge` заблокуйте або видаліть endpoint record у WinHUB за прийнятою процедурою.
