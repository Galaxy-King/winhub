# Встановлення macOS Agent

## Інтерактивне встановлення

У каталозі release package:

```bash
./setup-macos-agent.sh
```

Скрипт запитує URL і secrets без розміщення їх у shell history. Якщо перевірені `winhub_agent.conf` і `winhub_agent.bootstrap.conf` уже лежать поруч, він використає їх.

## Unattended deployment

```bash
sudo ./install-macos-agent.sh
```

Конфіги повинні бути підготовлені поруч із installer і видалені з тимчасового deployment location після завершення.

## Pin Apple Team ID

```bash
WINHUB_EXPECTED_TEAM_ID="<APPLE_TEAM_ID>" ./setup-macos-agent.sh
```

Unsigned binaries відхиляються. Не встановлюйте production agent із `WINHUB_ALLOW_UNSIGNED=1`.

## Перевірте

```bash
sudo launchctl print system/com.winhub.agent
tail -n 100 /Library/Logs/WinHUB/agent.log
```

Підтвердьте endpoint у Review Center.
