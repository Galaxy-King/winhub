# Встановлення macOS Agent

## Рекомендоване production-встановлення

Розпакуйте `macos-arm64-installer.zip` і в каталозі release bundle виконайте:

```bash
WINHUB_EXPECTED_TEAM_ID="<APPLE_TEAM_ID>" ./setup-macos-agent.sh
```

Скрипт перевіряє Developer ID Installer, Team ID і Gatekeeper, запитує URL/secrets без
розміщення у shell history, передає їх package installer через тимчасовий root-only staging
і перевіряє, що LaunchDaemon залишається запущеним.

## Unattended deployment

```bash
WINHUB_EXPECTED_TEAM_ID="<APPLE_TEAM_ID>" ./setup-macos-agent.sh \
  --pkg ./WinHUBMacAgent-v<VERSION>-macos-arm64.pkg \
  --config ./winhub_agent.conf \
  --bootstrap-config ./winhub_agent.bootstrap.conf
```

`.pkg` не містить tenant secrets. Конфіги мають mode `0600` і видаляються з deployment
location після завершення.

## Pin Apple Team ID

Unsigned binaries відхиляються. Не встановлюйте production agent із `WINHUB_ALLOW_UNSIGNED=1`.

## Перевірте

```bash
sudo launchctl print system/com.winhub.agent
tail -n 100 /Library/Logs/WinHUB/agent.log
sudo /Library/PrivilegedHelperTools/com.winhub.agent/diagnose-macos-agent.sh
```

Підтвердьте endpoint у Review Center.
