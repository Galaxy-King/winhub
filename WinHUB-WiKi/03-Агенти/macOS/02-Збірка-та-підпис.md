# Збірка і підпис macOS Agent

## Build host

Потрібні Apple Silicon Mac, .NET 8 Arm64 SDK, Xcode Command Line Tools і Developer ID Application certificate.

## Production release

```bash
WINHUB_CODESIGN_IDENTITY="Developer ID Application: <ORG> (<TEAM_ID>)" \
  ./create-macos-agent-release.sh
```

Скрипт:

- виконує NativeAOT publish;
- підписує всі Mach-O files із hardened runtime і timestamp;
- перевіряє version;
- запускає protocol self-test;
- створює versioned `macos-arm64.tar.gz` і SHA-256.

Для публічного distribution поза managed WinHUB updates підготуйте signed і notarized `.pkg`.

Локальна unsigned build дозволена лише для development і не повинна завантажуватися до production WinHUB.
