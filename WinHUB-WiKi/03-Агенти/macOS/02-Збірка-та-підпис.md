# Збірка і підпис macOS Agent

## Build host

Потрібні Apple Silicon Mac, актуальні Xcode та .NET 10 Arm64 SDK, `Developer ID Application`,
`Developer ID Installer` і збережений у Keychain profile для `notarytool`.

## Production release

```bash
WINHUB_CODESIGN_IDENTITY="Developer ID Application: <ORG> (<TEAM_ID>)" \
WINHUB_INSTALLER_IDENTITY="Developer ID Installer: <ORG> (<TEAM_ID>)" \
WINHUB_NOTARY_PROFILE="winhub-notary" \
  ./create-macos-agent-release.sh
```

Скрипт:

- виконує NativeAOT publish;
- підписує всі Mach-O files із hardened runtime і timestamp;
- перевіряє version;
- запускає protocol self-test;
- створює versioned `macos-arm64.tar.gz` і SHA-256 для managed update;
- створює signed `.pkg`, перевіряє збіг Team ID;
- виконує Apple notarization, stapling і Gatekeeper assessment;
- створює installer ZIP і SHA-256.

`Developer ID Application` і `Developer ID Installer` виконують різні ролі; одного
сертифіката недостатньо. Notarization profile зберігає secret у Keychain, а release script
отримує лише його ім’я.

Локальна unsigned build дозволена лише для development і не повинна завантажуватися до production WinHUB.

Повна процедура: [інструкція збірки](../../../WinHUBMacAgent/docs/BUILD_MAC_M4_UA.md).
