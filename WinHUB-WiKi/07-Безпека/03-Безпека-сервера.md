# Безпека сервера

## Базові controls

- Debian security updates;
- SSH лише для довірених адміністраторів;
- Nginx TLS 1.2/1.3;
- backend і PostgreSQL на localhost;
- systemd hardening і `NoNewPrivileges`;
- ізольований no-network Report Renderer;
- root-owned env/TLS files;
- окремий service user;
- HSTS, secure cookies і CSP nonce;
- outbound host allowlist;
- rate limiting;
- log/audit retention;
- encrypted off-host backups.

## Заборонені shortcuts

- відкриття `8443` або `5432` у public network;
- `IgnoreTlsCertificateErrors=true`;
- world-readable env/key files;
- зберігання secrets у Git/WiKi;
- `REPORT_RENDERER_MODE=inprocess` у production;
- global outbound bypass замість точного allowlist.
