# Ротація секретів

Ротація виконується за change plan із backup, rollback і перевіркою залежностей.

| Секрет | Наслідок зміни |
| --- | --- |
| `SECRET_KEY` | Завершення sessions; можливий вплив на signed/session data. |
| PostgreSQL password | Потрібна синхронна зміна role і `winhub.env`. |
| `AGENT_API_KEY` | Впливає на новий enrollment, не на enrolled tokens. |
| Task signing secret | Може вплинути на agents у transitional HMAC mode. |
| TLS private key/cert | Потрібне оновлення trust/pin агентів. |
| Master/system encryption keys | Без планової re-encryption старі дані стануть недоступними. |

Encryption keys не ротуються простим видаленням файлів. Така дія призведе до втрати доступу до зашифрованих даних.

Нові secret values передавайте лише через secret manager.
