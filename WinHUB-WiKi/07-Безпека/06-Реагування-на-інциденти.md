# Реагування на інциденти

## Компрометація endpoint-а

1. Block endpoint у WinHUB.
2. Ізолюйте його мережево.
3. Збережіть logs/state для forensic analysis.
4. Визначте exposed task/output data.
5. Reinstall/purge agent identity за контрольованою процедурою.
6. Allow re-enroll лише для конкретного endpoint і часу.

## Компрометація server/recovery bundle

1. Ізолюйте сервер, але збережіть volatile evidence.
2. Відкличте active sessions/API keys/integration tokens.
3. Закрийте enrollment.
4. Ротируйте TLS, DB, enrollment і task-signing credentials за планом.
5. Оцініть необхідність відновлення із trusted backup.
6. Перевірте agent identities і task history.

Не публікуйте forensic artifacts у WiKi. У документації зберігайте лише timeline, рішення та redacted indicators.
