# Діагностика сервера

## Швидка перевірка

```bash
sudo /opt/winhub/deploy/debian/healthcheck_winhub.sh
sudo systemctl status winhub --no-pager --full
sudo systemctl status winhub-renderer.socket --no-pager --full
sudo nginx -t
```

## Логи

```bash
sudo journalctl -u winhub -n 150 --no-pager
sudo journalctl -u 'winhub-renderer@*' -n 100 --no-pager
sudo tail -n 150 /var/log/winhub/winhub_prod.log
sudo tail -n 100 /var/log/nginx/error.log
```

Перед передаванням логів видаліть tokens, email, IP, report content і payload data.

## Типові причини

| Симптом | Перевірка |
| --- | --- |
| `502 Bad Gateway` | Статус `winhub`, binding `127.0.0.1:8443`, Nginx error log. |
| WinHUB не стартує | PostgreSQL, production secret validation, permissions, migrations. |
| Renderer failed | Socket service, `/run/winhub-renderer.sock`, renderer journal. |
| TLS warning | SAN, строк дії, trust chain, fingerprint. |
| Agent не підключається | HTTPS reachability, certificate pin, clock, enrollment policy. |
| Integration blocked | `OUTBOUND_POLICY_MODE` та `OUTBOUND_ALLOWED_HOSTS`. |

Не виправляйте production-проблеми глобальним вимкненням TLS, signatures, CSP або outbound policy.
