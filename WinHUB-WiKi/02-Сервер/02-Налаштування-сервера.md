# Налаштування сервера

Основний production-конфіг:

```text
/etc/winhub/winhub.env
```

Права мають залишатися `0640`, власник `root`, група `winhub`.

## Групи параметрів

| Група | Приклади |
| --- | --- |
| Runtime | `HOST`, `PORT`, `DATA_DIR`, `SERVER_LOG_FILE` |
| PostgreSQL | `POSTGRES_HOST`, `POSTGRES_PORT`, `POSTGRES_DB`, `POSTGRES_USER` |
| Sessions | `SESSION_COOKIE_SECURE`, `SESSION_COOKIE_SAMESITE`, timeouts |
| Agent Gateway | enrollment, signature, polling і package settings |
| Security | CSP, HSTS, outbound policy, report renderer |
| Retention | `LOG_RETENTION_DAYS`, `AUDIT_RETENTION_DAYS` |
| Integrations | SMTP, IMAP, LDAP, FreeIPA, GPG |

## Безпечне редагування

```bash
sudoedit /etc/winhub/winhub.env
sudo systemctl restart winhub
sudo /opt/winhub/deploy/debian/healthcheck_winhub.sh
```

Не копіюйте файл у Git або WiKi. Перед зміною секретів підготуйте план ротації: зміна enrollment/task-signing значень може вплинути на агентів.

## Строгі defaults нової інсталяції

Новий інсталятор вмикає CSP nonce enforcement, outbound enforcement, signed agent requests і Task v2. Для зовнішніх SMTP/LDAP/FreeIPA/Confluence інтеграцій спочатку додайте потрібні адреси до allowlist, а не вимикайте outbound policy глобально.
