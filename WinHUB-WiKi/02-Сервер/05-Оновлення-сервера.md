# Оновлення сервера

Оновлення виконує backup, отримує новий код, синхронізує нові env-параметри без заміни наявних значень, оновлює dependencies, застосовує migrations, перезапускає служби та робить healthcheck.

## Стандартне оновлення з Git

```bash
cd /opt/winhub
sudo bash deploy/debian/update_winhub.sh
```

## Оновлення до конкретного Git ref

```bash
cd /opt/winhub
sudo bash deploy/debian/update_winhub.sh <TAG_OR_COMMIT>
```

## Перевірка

```bash
sudo /opt/winhub/deploy/debian/healthcheck_winhub.sh
sudo systemctl status winhub --no-pager
sudo journalctl -u winhub -n 100 --no-pager
```

## Важливо

- Не запускайте `install_debian.sh` для звичайного оновлення.
- Не замінюйте `winhub.env` шаблонним файлом.
- Переконайтеся, що backup перенесено до off-host storage.
- Для великих fleet оновлюйте агентів окремими хвилями після стабілізації сервера.
