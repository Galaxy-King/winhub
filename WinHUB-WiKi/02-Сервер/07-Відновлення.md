# Відновлення сервера

Відновлення є адміністративною операцією з downtime. Перед початком перевірте точний каталог backup і його контрольні суми.

## Команда

```bash
sudo /opt/winhub/deploy/debian/restore_winhub.sh \
  /var/lib/winhub/backups/<UTC_TIMESTAMP>
```

Скрипт відновлює application files, `/etc/winhub`, runtime data та PostgreSQL dump, після чого перевстановлює dependencies, запускає служби й виконує healthcheck.

## Після відновлення

```bash
sudo systemctl status winhub --no-pager
sudo nginx -t
sudo /opt/winhub/deploy/debian/healthcheck_winhub.sh
```

Додатково перевірте:

- вхід адміністратора і MFA;
- відкриття зашифрованих звітів;
- agent poll і telemetry;
- task signature verification;
- TLS certificate fingerprint;
- Audit Log.

Якщо відновлення виконано на іншій адресі, спочатку підготуйте DNS/TLS і лише потім повертайте агентів у production.
