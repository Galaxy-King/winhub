# Перший вхід

Дані першого адміністратора містяться лише в одноразовому recovery bundle, який інсталятор просить зберегти поза сервером.

## Порядок дій

1. Відкрийте `https://<WINHUB_SERVER>`.
2. Введіть username `admin` і випадковий password із recovery bundle.
3. Додайте TOTP seed до захищеного authenticator.
4. Перевірте вхід із MFA.
5. Негайно змініть password.
6. Створіть окремий іменний admin-акаунт для щоденної роботи.
7. Залиште аварійний обліковий запис під контролем відповідальної особи.

## Після входу

- перевірте `Production Readiness`;
- перевірте modules і permissions;
- не відкривайте enrollment для ширшої мережі без потреби;
- додайте один тестовий endpoint;
- перевірте Audit Log.

Не переносіть admin password або TOTP seed до Confluence.
