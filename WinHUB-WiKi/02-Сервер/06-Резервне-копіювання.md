# Резервне копіювання

## Створення backup

```bash
sudo /opt/winhub/deploy/debian/backup_winhub.sh
```

За замовчуванням backup створюється у:

```text
/var/lib/winhub/backups/<UTC_TIMESTAMP>
```

## Що входить

- application archive;
- PostgreSQL custom dump;
- `winhub.env`;
- TLS certificate/private key;
- runtime data;
- `master_key.enc` та `sys_secret.enc`;
- metadata і SHA-256 checksums.

## Критична вимога

Локальна копія не захищає від втрати сервера. Після створення перемістіть backup до зашифрованого off-host сховища та обмежте доступ.

## Перевірка

- перевірте `backup.json`;
- перевірте `SHA256SUMS`;
- переконайтеся, що присутній PostgreSQL dump;
- регулярно виконуйте test restore на ізольованому сервері;
- не публікуйте список файлів із sensitive metadata у WiKi.
