# Ручний імпорт Telegram Desktop для Windows / RDS

Імпортуйте [telegram_rds_pack.json](../../../WinHUB/deploy/import_templates/telegram_rds/telegram_rds_pack.json) у бібліотеку шаблонів WinHUB. Перевірте й погодьте action-шаблон `Telegram Desktop — Windows / RDS`. Спочатку виконайте `Audit` на тестовому Windows-хості. Для встановлення потрібний HTTPS-доступ до офіційного завантаження Telegram.

| Action | Поведінка |
| --- | --- |
| `Audit` | Показує наявність програми, ярликів, блокатора updater і спільного `tdata`; нічого не змінює |
| `Install` | Завантажує актуальний офіційний інсталятор, перевіряє Authenticode та видавця Telegram, встановлює або оновлює програму й створює ярлики |
| `Repair` | Відновлює ACL та ярлики наявної програми без завантаження |
| `Uninstall` | Видаляє спільну програму та керовані ярлики, зберігає персональні дані |

`AutoUpdate=Blocked` замінює `Updater.exe` захищеним каталогом. Для оновлень повторіть `Install`. `Allowed` не створює блокатор; щоб відновити раніше видалений updater, потрібен `Install`, а не `Repair`. Звичайні користувачі мають лише читання/виконання у Program Files, тому `Allowed` не гарантує самостійного оновлення без адміністративних прав.

## Окремі акаунти

Сфера цього пакета — усі Windows-користувачі, включно з майбутніми користувачами RDS. Спільні лише файли програми та ярлики. Ярлик запускає захищений `WinHUB-Telegram-Launcher.ps1` із каталогу програми через PowerShell без профілю в контексті користувача, визначає його AppData та Windows SID, створює `%APPDATA%\WinHUB Telegram-<Windows SID>` та передає фактичний шлях через `-workdir`. AppData служби LocalSystem не підставляється при встановленні. Каталог і його вміст доступні цьому користувачу, SYSTEM і адміністраторам.

Запуск від SYSTEM/LocalService/NetworkService відхиляється. Якщо каталог належить іншому SID, шлях або його вміст містить junction/symlink, чи захист прав завершується помилкою, Telegram не запускається. Наявні явні ACL вкладених файлів скидаються до успадкованих прав персонального каталогу. SID у назві розділяє шляхи навіть за однакової AppData; права батьківських каталогів і мережевих сховищ мають бути налаштовані адміністратором. SID не захищає від адміністратора ОС або навмисного копіювання сесії самим власником.

Ярлик використовує `-ExecutionPolicy Bypass` лише для свого процесу; системна execution policy не змінюється, а доменні політики можуть забороняти запуск. Після імпорту попередньої версії пакета повторно імпортуйте оновлений JSON та виконайте `Repair` або `Install`, щоб оновити launcher і ярлики. Старий каталог без SID автоматично не переноситься й не видаляється.

Кожен користувач сам входить у свій Telegram-акаунт. Скрипт не створює акаунти Telegram й не копіює сесії, телефони чи коди авторизації. Потрібні різні Windows-профілі: спільний Windows-логін означає спільний профіль Telegram. Адміністратори ОС залишаються довіреними та мають доступ до даних.

Запускайте Telegram через створені ярлики. Старі ярлики, автозапуск і обробники `tg://` не переналаштовуються цим пакетом; вони можуть використовувати інший профіль. Наявні персональні Telegram-сесії не переносяться — у новому каталозі потрібна повторна авторизація. Виявлення `tdata` у спільному каталозі програми блокує зміни: адміністратор має спочатку вручну зберегти й розібрати ці дані.

Режими зміни зупиняють процеси Telegram/updater лише з керованого каталогу на всіх сесіях цього хоста. Плануйте їх поза робочим часом. Результат повертається як JSON у результаті задачі; окремого report-шаблону немає. `Audit` показує стан файлів, а не підтверджує успішний вхід чи повну ізоляцію активних RDS-сесій. Політики Windows можуть забороняти PowerShell у ярликах; перевірте запуск під двома звичайними користувачами перед масовим розгортанням.

Пакет не видаляє персональні профілі. Інсталяція/оновлення не є транзакційними: помилка після запуску інсталятора може залишити частково змінену програму; усуньте причину й повторіть `Install` або `Repair`.

`-workdir` наразі документований Telegram як legacy-параметр: [офіційна Wiki Telegram Desktop](https://github.com/telegramdesktop/tdesktop/wiki/Command-Line-Switches). Після оновлень Telegram перевіряйте відкриття правильного профілю перед масовим rollout.
