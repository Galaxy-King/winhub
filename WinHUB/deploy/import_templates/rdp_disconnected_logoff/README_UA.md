# Вихід із відключених RDP-сесій

Для ручного імпорту використовуйте `rdp_disconnected_logoff_pack.json`. Джерело — `rdp_disconnected_logoff.ps1`; генерація пакета — `python build_pack.py`.

Пакет містить дію `RDP — Log off disconnected users` та пов'язаний структурований HTML-звіт `RDP Session Report` (джерело `rdp_disconnected_logoff_report.jinja`). Після імпорту погодьте обидва шаблони й створіть нову задачу. Звіт містить підсумки по серверах і таблиці активних, завершених, кандидатів Audit, пропущених сесій та помилок. Для перегляду таблиць натисніть Preview. Повторний імпорт оновлює попередній шаблон дії; старі snapshots не переформатовуються.

Інструкція й обмеження: [Wiki](../../../../WinHUB-WiKi/guides/features/RDP_DISCONNECTED_LOGOFF_UA.md).

Назва й увесь текст звіту — англійською: **RDP Session Report**. Після оновлення пакета повторно імпортуйте та погодьте обидва шаблони, потім створіть нову задачу Audit. Старі результати не перераховуються.
