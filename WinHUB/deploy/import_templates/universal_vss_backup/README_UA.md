# Universal VSS Backup

`universal_vss_backup_template_pack.json` — пакет шаблонів універсального резервного копіювання та звіту. Імпортуйте його через бібліотеку шаблонів Infrastructure після перевірки скриптів і змінних.

Пакет перенесено з `deploy/` до спільного каталогу `deploy/import_templates/`. Для окремого сценарію VSS + WinRAR дивіться [відповідний пакет](../vss_winrar_backup/README_UA.md).
