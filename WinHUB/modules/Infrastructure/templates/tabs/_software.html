Сховище OMV та спільні ліміти

OMV доступний лише серверу WinHUB. Агенти отримують файли через HTTPS WinHUB.

Для приватного OMV також додайте його hostname/IP до OUTBOUND_ALLOWED_HOSTS. HTTPS перевіряється завжди; власний CA встановлюється на сервері та, для WinHUB, на кінцевих хостах.
